# TECNOVICE TECH SUMMIT 2026

A responsive two-page conference website for the Tecnnovice Tech Summit 2026 event held in Molyko, Buea.

TECNOVICE TECH SUMMIT 2026 is a personalized recreation of a conference website design, featuring a home page and about page with mobile and desktop layouts.

## 🛠 Built With

### Tech Stack

**Client**
- HTML5
- Bootstrap
- CSS3
- JavaScript (Vanilla)

### Key Features

- Fully responsive design (mobile ≤ 768px and desktop ≥ 768px)
- Dynamic Featured Speakers section generated with JavaScript
- Mobile hamburger menu with overlay and close button

## Getting Started

To get a local copy up and running, follow these steps.

### Prerequisites

In order to run this project you need:
- A modern web browser (Chrome, Firefox, Edge, Safari)
- A code editor (optional, for making changes)

### Setup

Clone this repository to your desired folder:

git clone https://github.com/ziggy-beep/tecnnovice-tech-summit-2026.git


Install
No installation is required. This is a static website.
Usage
To run the project, open the  file in your browser:
# On Windows
start index.html

# On macOS
open index.html

# On Linux
xdg-open index.html
Or simply double-click the  file.
Run tests
No automated tests are included in this project.
Deployment
You can deploy this project using:

GitHub Pages
Netlify
Vercel
Any static hosting service
